ReSo Ekstensi

Rekap Engagement Sosmed — Browser Extension

Download Extension (.zip) — Disarankan Download .crx — Opsi Drag & Drop
  1. Klik tombol Download untuk mengunduh file .zip.
  2. Buka halaman chrome://extensions di browser Chrome.
  3. Aktifkan Developer mode (sudut kanan atas).
  4. Ekstrak file .zip, lalu klik Load unpacked dan pilih folder hasil ekstrak.
  5. Klik Add extension saat muncul konfirmasi.
  6. Buka ReSo, klik ikon extension, lalu klik Login ke ReSo.
Catatan: Bila memilih .crx, drag & drop ke chrome://extensions. Jika muncul CRX_REQUIRED_PROOF_MISSING, gunakan file .zip (Load unpacked). Extension memerlukan akses host — klik Allow saat diminta.
