Rekap Engagement Sosmed — Browser Extension

Download Extension (.crx)
  1. Klik tombol Download di atas untuk mengunduh file .crx.
  2. Buka halaman chrome://extensions di browser Chrome.
  3. Aktifkan Developer mode (sudut kanan atas).
  4. Drag & drop file .crx yang sudah diunduh ke halaman chrome://extensions.
  5. Klik Add extension saat muncul konfirmasi.
  6. Buka ReSo, klik ikon extension, lalu klik Login ke ReSo.
Catatan: Extension memerlukan akses ke domain ReSo Anda. Saat pertama kali login, Chrome akan meminta izin host — klik Allow.
